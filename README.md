# MI_Estadistica 📊

Este repositorio centraliza herramientas, scripts y modelos para el análisis estadístico descriptivo e inferencial. Está diseñado para procesar grandes conjuntos de datos y generar indicadores clave que faciliten la toma de decisiones basada en evidencia.

## 🚀 Propósito del Proyecto

Desarrollar un entorno de análisis estadístico robusto que permita la auditoría de datos, la identificación de tendencias y el modelado de comportamientos. Este proyecto integra la experiencia en sistemas financieros para garantizar la precisión y la integridad de los resultados.

## 📁 Estructura del Repositorio

Organizado bajo un esquema de gestión profesional:

* **src/**: 
  * Algoritmos de cálculo de medidas de tendencia central y dispersión.
  * Scripts para la generación de histogramas y distribuciones de frecuencia.
  * Módulos en Visual Basic 6 y SQL para el procesamiento masivo de registros.
* **docs/**: Documentación sobre metodologías estadísticas y normativas de auditoría (ej. BCRA).
* **results/**: Reportes generados, gráficos estadísticos y tablas de contingencia.

## 🛠️ Capacidades Técnicas

* **Análisis de Datos Bancarios**: Herramientas preparadas para la validación de integridad y detección de anomalías en bases de datos críticas.
* **Automatización de Reportes**: Generación de salidas estructuradas para la documentación de hallazgos técnicos.
* **Modelado Probabilístico**: Aplicación de distribuciones de probabilidad para el análisis de riesgos y proyecciones de sistemas complejos.
